# Žanr

Web of Planets je **hibrid žanrova**: [[Survival žanr|survival]] + [[Factory žanr|factory/automatizacija]], s elementima istraživačkog sandboxa. Jednom rečenicom: *„3D space survival/factory igra"*.

## Koji element pripada kojem žanru

| Element igre | Žanr |
| --- | --- |
| Zdravlje, opasne zone, neprijatelji, plinska maska | [[Survival žanr\|Survival]] |
| Ručno rudarenje i ograničeni inventar | [[Survival žanr\|Survival]] |
| Strojevi za skupljanje i proizvodnju, recepti | [[Factory žanr\|Factory]] |
| Mreža veza, transport, održavanje | [[Factory žanr\|Factory]] + strategija |
| Proceduralni planeti, slobodno istraživanje | Sandbox / istraživanje |

## Zašto hibrid

- Survival dio daje **pritisak i rizik** (zdravlje, hazardi, troškovi) — razlog da igrač pazi *gdje* ide.
- Factory dio daje **dugoročnu progresiju** (ručno → alati → automatizacija) — razlog da igrač planira *što* gradi.
- Kombinacija tjera na balans: automatizacija oslobađa vrijeme, ali mreža koja je nosi traži održavanje.

## Moguća potpitanja

- *„U koji biste žanr svrstali igru?"* → hibrid; navesti tablicu gore.
- *„Po čemu je survival, kad nema gladi/žeđi?"* → survival ovdje znači upravljanje zdravljem i rizikom okoline (lava, plin, mobovi), ne metabolizmom — bliže *Subnautici* nego *DayZ-u*.
